#### OPP-2026-07-01-033 · 🔴 装配防错系统（强制按图装配）

| 字段 | 值 |
|---|---|
| 流程节点 | [3] 装配执行 |
| 机会类型 | **双路并行**（AI + 软件）|
| 痛点类型 | 经验依赖 + 实时性差 |
| 优先级 | **P0 · 公司级 Top 1 痛点** |
| 价值密度 | ⭐⭐⭐⭐⭐（5.0）|
| 实施成本 | ⭐⭐⭐⭐（4.0）|
| **ROI** | **1.25** |
| AI 可行性 | ⭐⭐⭐（3.5）|
| 软件可行性 | ⭐⭐⭐⭐（4.0）|

**现状**：**公司核心痛点**（业务背景 + 装配工艺工程师 JD 反复提到）—— 装配时常自行改动设计，"现场改一下"，导致同型号设备内部不一致。

**严重后果**：
- **质量风险**：客户收到"不一致"的设备，可能拒收或索赔
- **售后成本飙升**：每台不一致设备都可能产生售后问题
- **品牌信誉受损**：客户口碑下降，影响后续订单

**痛点**：
- **装配过程无记录**：谁在什么时候改了什么？无法追溯
- **SOP 难落地**：装配现场"灵活操作"成常态
- **事后才发现**：质量稽核滞后到出厂前

**方案**：
- **软件路线（强制按图装配系统）**：
  - 装配工位扫码/刷脸 → 自动加载本工位 SOP
  - 关键工序必须拍照/视频存档
  - 偏离 SOP 时自动告警 + 锁定工位
  - 装配过程全程追溯（操作员/时间/物料批次/SOP 版本）

- **AI 路线（视觉识别 + 智能纠错）**：
  - 装配关键步骤视觉识别（AI 判断"是不是按图装"）
  - 异常操作识别（漏装/错装/顺序错乱）
  - 装配过程视频自动分析

**价值**：
- **质量事故 0 容忍**：装配擅自改动设计 = 0
- **客户满意度提升**：设备一致性提升 → 售后问题 -50%
- **质量追溯 100%**：所有装配过程可回溯

**跨中心联动**：
- **与装备研发 OPP-014（图纸 PLM）联动**：装配现场调用最新图纸
- **与质量管理 OPP-038（SOP 联动设计变更）联动**：设计变更触发 SOP 自动更新
- **与质量管理 OPP-037（装配一致性稽核）联动**：稽核从"事后"变"实时"

**承接**：行政运营中心信息化组（主导）+ AI 3D 事业中心（视觉 AI）+ 质量管理协同

#### OPP-2026-07-01-034 · 装配过程实时记录与异常上报

| 字段 | 值 |
|---|---|
| 流程节点 | [3] 装配执行 + [4] 装配问题反馈 |
| 机会类型 | 软件路线 + AI 增强 |
| 痛点类型 | 信息断层 + 实时性差 |
| 优先级 | **P0** |
| 价值密度 | ⭐⭐⭐⭐⭐（5.0）|
| 实施成本 | ⭐⭐⭐（3.0）|
| **ROI** | **1.67** |

**现状**：装配问题反馈给装备研发靠"叫过来看一眼"（业务背景已确认）。**装配现场问题反馈链路长**：
- 装配发现问题 → 班组长 → 装配工艺工程师 → 装备研发 → 研发到现场
- **平均响应时间 X 天**

**痛点**：
- **响应慢**：影响装配进度
- **反馈内容散落**：微信/口头/工单，装备研发收不到完整信息
- **同类问题反复出现**：没有"问题库"，每次都要研发重新诊断

**方案**：
- **装配工位移动端**（PAD/PDA）：
  - 问题上报：拍照/视频/语音/文字，自动定位设备型号
  - 工单流转：自动路由到对应装备研发工程师
  - 处理进度实时推送：装配工位能看到研发处理到哪一步
- **AI 增强（问题智能分类 + 知识库匹配）**：
  - 上报问题自动分类（机械/电气/软件/工艺）
  - 匹配历史问题库：这个问题以前出现过吗？解决方案是？
  - 自动推荐解决方案（基于历史 + SOP）

**价值**：问题反馈响应时间从 X 天降到 2-4 小时；同类问题复发率 -60%

**承接**：行政运营中心信息化组 + AI 3D 事业中心（LLM 知识库）

#### OPP-2026-07-01-035 · 装配 SOP 智能检索与培训追踪

| 字段 | 值 |
|---|---|
| 流程节点 | [3] 装配执行 |
| 机会类型 | AI 路线 |
| 痛点类型 | 信息断层 + 经验依赖 |
| 优先级 | **P0** |
| 价值密度 | ⭐⭐⭐⭐（4.5）|
| 实施成本 | ⭐⭐⭐（3.0）|
| **ROI** | **1.5** |

**现状**：质量管理中心出 SOP（业务背景），装配现场查 SOP 靠纸质文件 + 个人记忆。**新人不会装、SOP 改版后没通知**。

**痛点**：
- **SOP 检索难**：纸质文件找不到，文件柜版本错乱
- **培训后落地差**：培训完不知道员工会不会
- **SOP 改版同步慢**：新版本 SOP 没及时下发到工位

**方案**：
- **SOP 智能检索系统**（移动端/PAD）：
  - 扫码查 SOP：扫设备型号/工位号 → 自动加载对应 SOP
  - SOP 改版自动推送 + 强制确认
  - 视频化 SOP（关键工序配视频）
- **AI 增强**：
  - 自然语言查询："这个电机怎么装？" → AI 检索 SOP + 历史案例
  - 培训效果智能测评（基于历史装配数据）
  - SOP 错误自动检测（与实际操作对比）

**价值**：SOP 查询时间 -80%；SOP 培训覆盖率 100%；装配错误率 -40%

**跨中心联动**：与质量管理 SOP 体系深度联动（详见质量管理清单）

**承接**：AI 3D 事业中心（LLM + RAG）+ 质量管理协同
