# AI 机会清单 — 行政运营中心 + PMOC（信息化项目统筹）

> **生成时间**：2026-07-01
> **范围**：行政运营中心（16 人）+ PMOC（13 人，散在行政下，JD 实际为项目管理经理）
> **核心岗位**：行政运营中心负责人 / 流程优化与信息化建设经理 / 信息化建设工程师 / 项目管理经理（PMOC）
> **挖到机会**：9 个（**P0=4 / P1=3 / P2=2**）
> **关键痛点**：流程优化、ERP/OA/CRM/BI 系统实施、跨部门数字化转型、政府关系、项目协同、文档协同

> ⚠️ **这个中心是公司几乎所有 AI/软件项目的"承接方"**：其他中心提出的 AI/软件需求，最终都要落到"行政运营中心信息化组"实施。所以本清单重点不是"行政自己的痛点"，而是它**作为承接方能提供的服务/能力**。

---

## 一、行政运营流程概览（简）

行政管理 → 流程优化 → 信息化系统规划 → 数字化转型推动 → 项目协调 → 政府关系

#### OPP-088 · 跨部门流程优化与再造（横向拉通）

| 项 | 内容 |
|---|---|
| 流程节点 | 流程优化 |
| 类型 | **软件 + AI** |
| ROI | **1.8** |
| 周期 | 5 人月 |
| 痛点类型 | 信息断层 |

**现状**：流程优化经理 JD 明确"诊断现有业务流程痛点，设计优化方案并推动实施（如审批流程、生产流程、供应链流程等），**目标效率提升≥20%**"。**当前跨部门流程靠人工跟**。

**方案**：业务流程梳理（BPMN 建模）+ 流程优化工作坊 + 流程自动化引擎（审批/通知/数据流转）+ 流程效率实时监控。

**承接范围**：跨所有中心（采购/装备/电池/生产/产线/质量/销售/财务/HR）的流程优化。

**价值**：跨部门流程效率 +20-30%；流程变更追溯 100%。

#### OPP-089 · 飞书 + AI 智能办公生态建设

| 项 | 内容 |
|---|---|
| 流程节点 | 信息化基础 |
| 类型 | **软件 + AI** |
| ROI | **1.6** |
| 周期 | 6 人月 |
| 痛点类型 | 信息断层 |

**现状**：信息化建设工程师 JD 明确"负责飞书套件（即时通讯、云文档、日程管理等）与 AI 能力的融合拓展"。**当前飞书基础已部署，但 AI 融合刚起步**。

**方案**：飞书 + AI 全场景应用：
- 智能文档（自动生成/摘要/翻译）
- 智能会议（自动纪要/待办提取）
- 智能审批（规则引擎 + LLM）
- 智能搜索（基于历史对话/文档）
- 多维表格 + AI（自动分析/可视化）

**承接范围**：全员（197 人）。

**价值**：办公效率 +30-50%；跨部门信息流动 -80% 阻力。

#### OPP-090 · 项目协同与进度智能管理（PMOC）

| 项 | 内容 |
|---|---|
| 流程节点 | 项目协同 |
| 类型 | **软件 + AI** |
| ROI | **1.6** |
| 周期 | 5 人月 |
| 痛点类型 | 信息断层 + 实时性差 |

**现状**：项目管理经理 JD 明确"监控执行过程中的进度偏差、成本支出与质量达标情况"，**当前靠 Excel + 会议 + 飞书文档**。**PMOC 是跨部门项目统筹中枢**（business-context.md），但本身没有专门的项目协同平台。

**方案**：项目协同平台（甘特图/资源调度/风险管理/项目文档）+ AI 项目预警（延期/超支/风险信号识别）+ 项目复盘知识库。

**承接范围**：PMOC + 各中心项目经理 + AI 落地项目。

**价值**：项目延期率从 X → ≤10%（JD 目标）；项目协同效率 +40%。

### ⚠️ 关键角色：行政运营中心信息化组

**这是公司几乎所有 AI/软件项目的承接方**。他们的产能决定其他中心的机会能否落地。

**核心人员**：
- 流程优化与信息化建设经理（5+ 年经验，跨部门统筹）
- 信息化建设工程师（飞书生态开发）
- 项目管理经理（PMOC，项目落地）

**当前挑战**：从 JD 看，他们既要承担流程优化，又要承担所有系统实施，又要承担数字化转型推动。**资源可能不足**，需要扩充或外部支持。

### 跨中心联动

- **行政 ↔ 所有中心**：作为承接方，几乎所有机会都涉及
- **行政 ↔ 财务**：预算控制 / 政府资金追踪
- **行政 ↔ HR**：招聘/绩效/培训系统
- **PMOC ↔ 所有 AI 落地项目**：项目协同

### 承接方

- **内部承接**：行政运营中心信息化组 + PMOC
- **外部 SaaS**：飞书生态 / UiPath / 用友 BI / 等
