# output 目录

本目录存放 agent（opportunity-miner）产出的 AI / 软件机会清单。

**规则：**

- 这是**唯一允许 agent 写入产出文件的目录**。
- 文件命名：`AI机会清单-{{类型}}-{{YYYY-MM-DD}}.md`（详见 `AGENTS.md` 第七章命名规则）。
- 每份清单末尾带"交付备注"，标注路线分工建议、优先级 Top N、待业务方确认事项。
- ❌ 不要把原 `docs/` 下的输入知识源覆盖到这里冒充新生成——本目录只放 agent 新产出的。

**承接方约定：**

- **AI 路线机会** → AI 3D 事业中心承接（LLM 应用 / RAG / Agent / 多模态）
- **软件路线机会** → 行政运营中心信息化组承接（业务系统 / 工作流引擎 / 数据集成）
- **双路并行机会** → 两个小组都接收，由 PMOC 协调竞合

详见 `AGENTS.md` 第八章。
