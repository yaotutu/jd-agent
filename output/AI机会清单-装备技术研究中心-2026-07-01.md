#### OPP-2026-07-01-013 · 定制设备方案智能辅助设计

| 字段 | 值 |
|---|---|
| 流程节点 | [1] 需求接收 + [8] 定制设备改图 |
| 机会类型 | AI 路线 |
| 痛点类型 | 经验依赖 + 高频重复 |
| 优先级 | **P0** |
| 价值密度 | ⭐⭐⭐⭐⭐（5.0）|
| 实施成本 | ⭐⭐⭐（3.0）|
| **ROI** | **1.67** |
| AI 可行性 | ⭐⭐⭐⭐（4.0）|

**现状**：定制设备改图是装备研发的高频痛点（业务背景已确认）。每接到一个客户定制需求，工程师都要"从头画一遍"，即使相似度 70% 也基本重做。**历史项目库散落**（CAD 文件在不同工程师电脑里），无法复用。

**痛点**：
- **重复劳动严重**：类似定制需求反复重画
- **历史方案难检索**：想找"上次那个 XX 客户的相似方案"靠工程师记忆
- **新人培养慢**：新工程师不懂历史项目积累

**方案**：
- **LLM + RAG 历史方案库**：定制需求来了 → AI 检索历史相似方案 → 推荐 Top 3 参考
- **CAD 参数化模板**：把常用结构（外壳/把手/旋钮）参数化，定制时只改参数不重画
- **跨工程师知识沉淀**：把每个工程师脑子里的"XX 客户我做过"沉淀到系统

**价值**：定制设备设计周期从 X 周缩短到 X-Y 周；新人上手周期从 6 个月缩短到 2 个月

**跨中心联动**：**与采购 OPP-006（BOM 数据库）联动** — 定制方案库包含 BOM 信息，反哺采购

**承接**：AI 3D 事业中心（LLM + CAD 自动化组）

#### OPP-2026-07-01-014 · 图纸版本管理与变更追踪（PDM/PLM）

| 字段 | 值 |
|---|---|
| 流程节点 | [6] 设计评审 + [7] 设计输出 + [8] 改图循环 |
| 机会类型 | 软件路线 |
| 痛点类型 | 信息断层 + 实时性差 |
| 优先级 | **P0** |
| 价值密度 | ⭐⭐⭐⭐⭐（5.0）|
| 实施成本 | ⭐⭐⭐⭐（4.0）|
| **ROI** | **1.25** |
| 软件可行性 | ⭐⭐⭐⭐（4.0）|

**现状**：定制设备改图频繁（已知痛点），**图纸版本管理靠人**（文件命名+文件夹）。经常出现"装配用了旧版图纸"或"销售发了旧版给客户"的事故。

**痛点**：
- **版本错乱**：同一设备有多个版本图纸，靠人脑区分
- **变更追溯难**：改图历史散落，无法追溯"谁在什么时候改了什么"
- **跨部门不同步**：销售/采购/装配拿到的图纸版本可能不一致
- **设计评审纪要散落邮件**：追溯决策依据难（已知痛点）

**方案**：
- **PDM/PLM 系统**（如用友 PLM / 华天 PLM）：
  - 集中管理图纸版本（每改一次自动版本号）
  - 变更流程线上化（ECN 工程变更通知）
  - 跨部门权限分发（销售只能看最新归档版、采购只能看 BOM）
  - 设计评审与图纸关联（评审纪要挂在图纸上）

**价值**：图纸版本事故 0 发生；变更追溯从 X 天降到 1 小时

**跨中心联动**：**与生产交付直接相关** — 装配现场能拿到最新版本图纸

**承接**：行政运营中心信息化组（PLM 选型与实施）

#### OPP-2026-07-01-015 · BOM 智能生成与变更联动

| 字段 | 值 |
|---|---|
| 流程节点 | [7] 设计输出 + [8] 改图循环 |
| 机会类型 | **双路并行**（AI + 软件）|
| 痛点类型 | 高频重复 + 信息断层 |
| 优先级 | **P0** |
| 价值密度 | ⭐⭐⭐⭐⭐（5.0）|
| 实施成本 | ⭐⭐⭐⭐（4.0）|
| **ROI** | **1.25** |
| AI 可行性 | ⭐⭐⭐⭐（4.0）|
| 软件可行性 | ⭐⭐⭐（3.0）|

**现状**：JD 明确提到"电控 BOM 清单""机械 BOM 清单"——**当前靠人工从 CAD/Excel 导出 BOM**。改图后 BOM 容易漏更新，导致采购错买、装配缺料。

**痛点**：
- **BOM 维护靠人**：工程师改图后忘了同步 BOM
- **机械 BOM 和电装 BOM 分离**：装配现场要手动对齐两份 BOM
- **历史 BOM 无追溯**：想知道"这个零件历史上用了多少"靠 Excel
- **BOM 与采购脱节**：BOM 改了采购不知道（**与采购 OPP-006 强联动**）

**方案**：
- **软件路线（PLM/BOM 系统）**：CAD 自动提 BOM → 集中管理 → 与采购系统对接
- **AI 增强**：BOM 变更影响分析（哪些采购单要改 / 哪些订单受影响）；BOM 错误自动检测（漏项/重复项）

**价值**：BOM 准确率提升 → 采购错买率下降 → 物料积压/缺料减少

**跨中心联动**：**与采购 OPP-006 同根同源，建议合并立项** — 装备研发 BOM 系统 + 采购 BOM 数据库共用一套

**承接**：行政运营中心信息化组（主导）+ AI 3D 事业中心（AI 增强）

#### OPP-2026-07-01-016 · 电装图纸 / 接线图 AI 辅助设计

| 字段 | 值 |
|---|---|
| 流程节点 | [3] 电装设计 |
| 机会类型 | AI 路线 |
| 痛点类型 | 高频重复 + 经验依赖 |
| 优先级 | **P0** |
| 价值密度 | ⭐⭐⭐⭐（4.0）|
| 实施成本 | ⭐⭐⭐（2.5）|
| **ROI** | **1.6** |
| AI 可行性 | ⭐⭐⭐⭐（4.0）|

**现状**：电气工程师用 Eplan 画电气原理图、布局图、接线图。**重复工作量大**：相似设备的电装图纸结构高度相似，但仍要一张张重画。元件选型（传感器/控制器/驱动器）靠工程师经验。

**痛点**：
- **重复出图**：相似设备的接线图高度相似但仍手工画
- **元件选型靠经验**：选哪个品牌的 PLC / 传感器靠个人经验
- **错误难发现**：接线错误要等到装配时才发现

**方案**：
- **Eplan 模板库 + 参数化**：常用电装结构参数化，改参数不重画
- **AI 辅助接线推荐**：基于设备类型 → AI 推荐标准接线方案
- **元件选型知识库（RAG）**：基于历史项目 + 厂商资料 → AI 推荐元件组合
- **接线错误自动检测**：基于规则引擎 + AI 视觉，图纸阶段就发现接线冲突

**价值**：电装设计周期 -40%；接线错误率 -60%

**承接**：AI 3D 事业中心（LLM + Eplan 自动化）
