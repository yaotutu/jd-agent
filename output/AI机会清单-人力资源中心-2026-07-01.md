## 二、机会清单

### 🔴 P0 · 推荐先立项（4 个）

---

#### OPP-069 · 简历智能筛选与匹配

| 项 | 内容 |
|---|---|
| 流程节点 | 招聘筛选 |
| 类型 | **AI** |
| ROI | **2.0** |
| 周期 | 3 人月 |
| 痛点类型 | 高频重复 + 经验依赖 |

**现状**：招聘专员 JD 明确"高效、精准地筛选简历"。**招聘达成率 ≥90%**——还有 10% 没达成。**多渠道简历格式不一**（前程无忧/智联/BOSS/猎聘/内推/猎头），筛选靠人工。

**方案**：AI 简历解析（多格式统一）+ 岗位画像匹配（基于历史录用数据）+ Top N 推荐 + 智能问答初筛（电话/视频面试 AI 提问）。

**价值**：单份简历筛选时间从 5-10 分钟 → 30 秒；招聘达成率从 90% → 95%+；招聘周期 -30%。

---

#### OPP-070 · 薪酬核算自动化

| 项 | 内容 |
|---|---|
| 流程节点 | 薪酬核算 |
| 类型 | **软件** |
| ROI | **1.8** |
| 周期 | 3 人月 |
| 痛点类型 | 高频重复 |

**现状**：薪酬绩效专员 JD 提到"月度薪酬核算、个税申报"。**每月重复性高** + 准确率要求 100% + 涉及多个城市（西安+广州）。

**方案**：薪酬自动计算引擎（基本工资/绩效/补贴/个税/五险一金）+ 多城市社保公积金规则库 + 个税自动申报 + 电子工资条。

**价值**：月节省 30-40 工时；准确率 100%；支持异地多基地。

| 项 | 内容 |
|---|---|
| 流程节点 | 绩效考核 |
| 类型 | **软件 + AI** |
| ROI | **1.5** |
| 周期 | 4 人月 |
| 痛点类型 | 信息断层 |

**现状**：薪酬绩效专员 JD 明确"关键绩效指标的收集、统计与分析"。**跨部门数据收集靠人工**（邮件/Excel），OKR 复盘会议周期长。

**方案**：绩效数据中台（自动从各部门系统抓数）+ KPI/OKR 实时看板 + AI 异常检测 + 复盘会议智能辅助（数据自动汇总）。

**价值**：绩效数据收集从 1 周 → 实时；OKR 复盘会议效率 +50%。
