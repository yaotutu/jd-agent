## 一、公司核心业务

**做什么：** 制造并销售**固态电池制造设备**。

**交付给客户的是"设备 + 工艺方案"的组合**——

- 设备：客户买回去用来制造对应型号/规格的固态电池。
- 工艺：光有设备不够，还需配套的方法（用什么材料、什么参数）才能造出更好的电池。
  卖设备的同时要把工艺方案一起交付给客户。

## 二、两条价值链

### 链 1：单台设备出售

```
电池研发中心(探索工艺/材料/参数)
        │ 找到适配设备的最优方案
        ▼
装备研发(出图纸：设计 + 电装 + 软件 + 前装)
        │ 评估设计合理性，产生机加工需求
        ▼
生产交付(按研发要求装配 → 发货)
        ▼
客户

横向约束：工艺中心(挂在"质量"下) 出 SOP/工艺指导书，
        规范生产不走样（现状：装配时常自行改动设计，导致同型号设备内部不一致）
```

### 链 2：整条产线出售（金额高，常达千万级）

```
产线策划(按客户场地 + 技术要求设计整条产线)
        │ 决定每台设备用「标准设备」还是「定制设备」
        │  - 标准设备：已研发好的现成产品
        │  - 定制设备：如改颜色/改尺寸/改性能 → 需求回流给装备研发改图
        ▼
多台设备串成一条完整产线，整体交付客户
```

**产线策划 vs 装备研发的层次区别：**
- 装备研发：聚焦**单台设备**（不管标准还是定制，给一个设备出图纸/方案）。
- 产线策划：站得更高，看**整条产线**——设备组成、场地排布、多台设备能否串起来。

## 四、两个重要的"研发"概念区分

1. **电池工艺研发**（电池研发中心）：偏化学/材料，回答"用什么材料/参数造出好电池"。
2. **装备研发**（机械/电装/软件）：偏工程设计，回答"造什么设备、怎么造出来"。

两者配合：电池研发可能提出"我需要 9000 转的设备"→ 找装备研发去造。
正常情况下电池研发用现有设备找最优方案；现有方案不满足时，提需求给装备研发造新设备。
